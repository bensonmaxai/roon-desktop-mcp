# 社群發布文案

## Facebook／較完整版本

做了一個 Roon Desktop MCP，讓 AI 可以在 Windows 上觀察並操作 Roon App。

原本透過 Roon API 能處理播放控制，但整理永久歌單、拖曳曲目順序、進入設定頁，還是常常要回到桌面操作。這個專案就是把這一段接起來。

AI 先看畫面、找目標，再執行一次操作，完成後重新讀回結果。現在有 13 個 MCP 工具，包含截圖、本機 OCR、文字輸入、點擊、拖曳、捲動與視窗喚回。

它預設只開放觀察，使用者在本機設定開啟桌面輸入後才會送出操作。

歌單的建立、加入、排序、改名、移除和刪除，已用獨立測試歌單完成實機驗證。每個步驟都核對結果，未知狀態也會留下紀錄，避免重複操作。

目前支援 Windows，提供 35 類由 AI 助手逐步執行的引導流程。MUSE／DSP 參數寫入還沒驗收，這部分先說清楚。

專案資訊與文件在 GitHub。有在用 Roon，也想把 MCP 接到桌面操作的人，可以看看。

https://github.com/bensonmaxai/roon-desktop-mcp

## Threads／精簡版本

做了一個 Roon Desktop MCP，現在可以請 AI 在 Windows 上觀察並操作 Roon App。

先看畫面，再點擊、輸入、拖曳，最後讀回結果。

預設只開放觀察，使用者在本機設定開啟桌面輸入後才會送出操作。

目前有 13 個工具，歌單的建立、加入、排序、改名、移除和刪除，已用獨立測試歌單完成實機驗證。另有 35 類引導流程；MUSE／DSP 參數寫入尚未驗收。

程式與文件公開在這裡：
https://github.com/bensonmaxai/roon-desktop-mcp
